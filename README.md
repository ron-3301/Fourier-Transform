# Fourier-Transform
This script visualizes how complex signals are composed of simpler trigonometric functions. it calculates the magnitude and phase of a signals frequency components and demonstrates the iterative reconstruction of the original function.

The script performs spectral analysis on different waveforms, calculating magnitude and phase to demonstrate how periodic functions are constructed from a summation of sinusoids

Requirements
The script requires Python 3.x and the following libraries:

NumPy: For FFT calculations and array manipulation.

Matplotlib: For generating static plots and the FuncAnimation interface.

Pillow: Required as the engine to save and encode GIF animations.
